# PowerBarRations 控制台规格 v2 —— 分组侧边栏信息架构

> 本文件取代 [`ui-spec-v1.md`](ui-spec-v1.md) §5–§6 的**信息架构与页面结构**；
> v1 中仍与本文不冲突的组件细节、字段契约与验收条目继续有效。
> 数据来源仍以 [`api-spec-v1.md`](api-spec-v1.md) 为准；路由语义见
> [`routing-spec-v1.md`](routing-spec-v1.md)。

## 1. 为什么重写

v1 的导航按上游 SaaS 后台的数据库表组织：11 个一级入口、渠道/渠道状态/模型目录三处重复、
请求日志/审计/任务三个平级入口、每个对象一个居中大弹窗。单用户网关真正的工作方式是按问题：

1. 现在健康吗？
2. 哪里要处理？
3. 花了多少钱？
4. 客户端在调用什么？
5. 谁在服务它？
6. 刚才发生了什么？

v2 的 IA 只服务这六个问题。

## 2. 一级导航（分组侧边栏）

侧边栏分「控制中心」「系统」两个区块，共 10 个入口；只有「用量」「渠道与模型」「设置」
是可展开分组。实时路由是单一观察入口（拓扑 + 各渠道速度），数据概览紧随其后（时间区间
分析面），路由是配置面。

| 区块 | 入口 | 路由 | 说明 |
|---|---|---|---|
| 控制中心 | 实时路由 | `/live-routing` | 车道 → 网关 → 成员拓扑 + 各渠道实时输出速度 |
| 控制中心 | 数据概览 | `/overview` | 健康、吞吐、成本与用量分析（时间区间分析面） |
| 控制中心 | 路由 | `/routes` | 模型入口（路由键）与故障转移链 |
| 控制中心 | 渠道与模型 ▾ | `/connections/channels` | 渠道 / 渠道状态 / 模型目录 |
| 控制中心 | API 密钥 | `/keys` | 消费者凭据与访问策略 |
| 控制中心 | 用量 ▾ | `/logs/requests` | 请求 / 会话 / 上下文 |
| 系统 | 脱敏 | `/logs/masking` | 隐私脱敏设置、预览与命中记录 |
| 系统 | 审计日志 | `/logs/audit` | 管理操作审计 |
| 系统 | 系统任务 | `/logs/tasks` | 后台任务与执行状态 |
| 系统 | 设置 ▾ | `/system-settings/site` | 站点与品牌 / 模型与路由 / 控制台内容 / 运维 |

- **Playground 不是一级入口**：顶栏全局按钮 + `⌘K` 动作 + 路由行「试打」。
- 渠道 / 渠道状态 / 模型目录是「渠道与模型」分组下的三个独立页面，不再共用「连接」
  工作区页签；旧路径 `/connections/*` 全部保留，`/connections` 重定向到第一个可见入口。
- 分组标题只负责展开/收起，不触发页面跳转；子项才是真实路由，刷新/深链/后退可用。
- **设置不再使用替换侧边栏的 drill-in 页面**：设置是主侧边栏内的可展开分组，进入任一
  设置域后主侧边栏保持常驻；设置页内只渲染当前设置域的二级分节页签。
- 侧边栏不出现分组标题以外的徽章/计数；「用量」展开为 请求 / 会话 / 上下文，
  「渠道与模型」展开为 渠道 / 渠道状态 / 模型目录，「设置」展开为 站点与品牌 /
  模型与路由 / 控制台内容 / 运维。侧边栏负责工作区导航，页面内不再渲染与之重复的页签条。
- **中文侧边栏标签保持短名**：实时路由 / 数据概览 / 路由 / 渠道与模型 / API 密钥 / 用量 /
  脱敏 / 审计日志 / 系统任务 / 设置；分组内用 请求 / 会话 / 上下文 / 渠道 /
  渠道状态 / 模型目录 / 站点与品牌 / 模型与路由 / 控制台内容 / 运维。
  页面标题与正文仍使用各自的 i18n 键，不为导航字数改写全站标题。
- **数据概览是一级入口、实时路由之下第二位**（2026-11-20 用户裁决）：操作员看完实时拓扑
  的下一步就是看用量与成本；概览不再是「用量」分组的子项。
- **脱敏归系统区**（2026-11-20 用户裁决）：它是实例级配置（含命中记录），不是日志视图，
  不再挂在「用量」分组旁边。

## 5. 页面壳

所有控制台页面使用**唯一的** `ConsolePage` 页面壳（`WorkspacePage` 只是薄包装，不含页签）；旧的第二套壳（`SectionPageLayout`）合并进 `ConsolePage`，不得再新增平行实现：

- 标题：`h2`，16/18px、600；描述一行、≤75 字符。
- 一个页面只有一个 filled primary action；其余为 outline/ghost。
- 导航：工作区子项在侧边栏分组（`用量` / `渠道与模型` / `设置`）中展开；页面内
  **不渲染**与侧边栏重复的页签条，避免形成两套导航。设置页可渲染当前设置域的二级
  分节页签（这些分节不在侧边栏重复列出）。所有子项都是真实路由，刷新/深链/后退可用。
- 内容：单一滚动区；列表页保留 `DataTablePage` 的页脚分页 portal。
- 移动端：标题与操作堆叠；描述 `line-clamp-2`；表格切移动卡片或横向滚动。
- 移动端筛选一律不得把表格挤出首屏：渠道列表使用「Filters」按钮 + 右侧 Sheet；
  搜索、模型、协议、状态、标签都在 Sheet 内，按钮显示已选数量。
- 移动端时间档位使用下拉选择，不换行铺六个 Tab；路由页成员组默认折叠，
  车道卡片优先。

## 6. 工作区

### 概览

- 顶部：统一时间区间（六档 + 自定义）+ **单张「模型健康」面板**（2026-11-07 合并）：
  顶部摘要为折算成本 / Token 总量（窗口口径 + 环比）；主体表格列为
  模型 / 请求数 / 延迟 p50（p95 悬浮）/ 输出速度 / 实时流量 / 成功率。
  服务状态已并入本面板，不再单独占卡。
  - **「模型」列只显示对外模型（路由键）**：`GET /api/model-status?group_by=lane` 按
    `lane_name` 聚合，绝不出现上游真名（真名只在「实时路由」成员链与日志详情里）。
  - **空值一律 `—`**：窗口内没有输出 Token 等长句不写进单元格。
- **输出速度** = 该模型（或对外路由键）在所选窗口内**全部 completion_tokens / 窗口秒数**，
  回答"这个模型在统计范围内整体每秒产出多少输出 token"；不是单请求生成速度，
  也不筛干净样本。没有输出时显示 `—`。
- **实时流量**是近 15 分钟总 Token/秒（输入 + 输出，含重试），回答"现在处理多少量"，
  60s 刷新，页面隐藏时暂停；无近期流量显示 `—`。两列一个是输出吞吐、一个是总 token
  吞吐，不得合并。
- **干净样本生成速度**不再占用「输出速度」：只在渠道状态/模型明细里以
  「Generation speed (tok/s)」展示（成功且单次尝试、扣掉首字等待），作为诊断口径。
- 调用次数 / RPM / TPM 已从概览顶部移除（2026-11-07 用户裁决）；调用量看模型数据分析
  与统计表，不重复占首屏。
- 模型数据分析（全宽）：含「调用趋势 / 消耗趋势」两条同轴时间线，分别按请求数与
  折算成本聚合；另有消耗分布、调用次数分布与排行。
- 分组统计表（全宽）；**Token 排行榜已并入统计表**，用「按 Token」排序。
- **缓存与用量摘要**：模型健康摘要条新增「缓存命中率」与「缓存命中 Token」。命中率 =
  `cache_read_tokens / input_tokens`（数据源 `/api/stats` 汇总）；`input_tokens=0` 时显示
  `—`，**不得显示 0%**。`input_tokens` 已按 `usage_semantic` 归一（usage-spec §6.3）：
  Anthropic 的 input 不含缓存，需加上 cache_read/cache_write；OpenAI/Gemini 的 prompt 已含。
- **客户端分布**（全宽面板）：按 `GET /api/stats?group_by=client` 的请求数 / Token / 成本
  渲染客户端排行；展示用后端给的 `client_name`，按 `client_group` 归组：`script` 显示为
  「脚本」，已知 agent 用其显示名。没有可识别客户端时给空态「还没有可识别的客户端」，不伪造条目。
- **用量日历**（全宽）：最近 53 周的按天热力图，指标可切换「请求数 / Token / 成本」；数据源
  `/api/stats?granularity=day&group_by=lane` 汇总。无数据的日期是空白格，**不是 0 的深色格**。
  时间范围固定为最近 53 周，不受顶部时间区间影响，图例必须写明。

### 实时路由（`/live-routing`）

- **单一观察入口**：同一页上半部是实时拓扑，下半部是各渠道速度；不再另设「实时仪表盘」菜单。
  概览只保留健康、成本与用量分析，不再占用实时拓扑。
- **本页不提供时间区间与问题筛选**（2026-11-20 用户裁决）：拓扑与渠道速度都是实时量，
  窗口固定，页面上不再出现六档时间区间、自定义区间或「仅看问题」筛选。历史区间分析在
  数据概览页做。
- 实时路由卡：左栏车道（可用/总成员、模式、启停），中间网关节点，右栏选中车道的成员链；
  虚线连接。成员右侧显示运行态结论：当前成员、就绪、限流/冷却/熔断（带 `SSE` 每秒刷新的
  剩余时间）、半开、探活中、人工停用、渠道停用、不可用、上游连续拒绝（N 次）。
- 底部给「首选成员」、该车道最近 24 小时的请求/失败/成功率，以及最近一次请求的
  attempts 链；`/live-routing?lane=` 可深链。旧链接里的 `range`/`from`/`to`/`window`
  参数被丢弃（窗口已固定），不再作为有效深链参数。
- 数据源是 `/api/v1/route-events`（SSE）与 30s 健康轮询兜底；无车道时给「打开路由」入口。
- 页面标题只出现一次：实时路由卡隐藏自身标题，但保留 Live 徽章、车道数与当前车道信息。
- **渠道速度面板**（页内第二块，标题「渠道速度」）：
  - 固定 **30s 实时窗口**，**每 5s 自动刷新**，页面隐藏暂停，另给手动刷新。
    不提供时间档位切换（2026-11-20 用户裁决：渠道速度只看实时值）。
  - 顶部摘要：活跃渠道 / 渠道总数、合计输出速度、合计实时流量、窗口请求数、加权成功率。
  - 有流量的渠道用速度卡：渠道名、启用状态、输出速度（tok/s）、请求速率、
    p50/p95、成功率、输出 Token、实时流量；按输出速度 → 请求数 → 渠道名排序。
  - **两个指标都是该渠道在统计范围内的整体聚合，不是单个请求：**
    - **输出速度** = 该渠道在 30s 窗口内**全部 requests 的 completion_tokens 之和 /
      窗口秒数**。分母是墙钟秒数，包含空闲、排队和首字等待，所以会比单请求实测低。
    - **生成速度** = `Σcompletion_tokens / Σ生成耗时`（流式扣首字等待）。它把并发流
      叠加起来，等价于操作员同时开多路实测时的合计吐字速度。
    - **实时流量** 固定取近 15 分钟 `Σ(输入 + 输出 token) / 900`，统计该渠道**全部请求**
      （含失败与重试实际处理的输入 token），回答「该渠道现在总 token 吞吐多大」。
    - 两者都是渠道级吞吐；区别是「只算输出」还是「输入+输出」，以及窗口是否固定。
  - 顶部摘要的「合计输出速度 / 合计实时流量」才是当前页所有渠道的汇总；单行不是全站。
    输出速度与实时流量都统一显示为 `tok/s`。
  - 空闲/停用渠道收进紧凑的「空闲渠道」条带（名称 + 状态 + `—`），不铺大卡、
    不显示 0 冒充「速度为 0」。
  - 速度条以本窗口最高输出速度为基准归一化；窗口内没有输出 token 的渠道不画速度条。
  - 数据源 `GET /api/channel-speed?from=&to=`（api-spec §6.14）：`tokens_out / 30`
    提供整体输出速度；`tokens_total / 900` 提供固定 15m 实时流量。旧 `output_tps`
    （干净样本生成阶段速度）不再作为本页的「输出速度」，只保留作诊断字段。
  - 空态：窗口内没有任何渠道请求时给「窗口内暂无渠道流量」。

### 渠道 / 渠道状态 / 模型目录（「渠道与模型」分组下的三个页面）

- **渠道**（"Channels"，路径 `/connections/channels`）：表格（渠道/协议/状态/响应/用量/创建时间/操作）；行编辑走右侧 Sheet；页头「导出 CSV」（不含密钥）。
  - 操作列只常驻「编辑」与「测试连接」（测试为图标按钮，带 `aria-label`）；启停、状态、复制、删除等
    动作收进 `...` 菜单，**启用/暂停不得作为常驻红色文字按钮**（§7）。
  - **「测试连接」成功即清除惩罚态**（routing-spec §5.4）：成功后 toast 明示
    「连接正常，已清除该成员的冷却/熔断」，并在响应带 `penalty_cleared.lanes` 时列出受影响车道；
    本来就没有惩罚态时只报「连接正常」，不虚构清理条数。失败时保留上游原文与 `error_kind`，
    **不得**暗示运行态被改动。
  - **删除入口 = 退役确认（两步，design-v1 §7.9）**：点「删除」先调 `POST /channels/{name}/retire?dry_run=true`
    拿预览——弹窗列出将停用、将从哪些车道清理/哪些车道整条删除、受影响的成员组（含**通过组受影响的
    其他车道**，明示共享链的连带影响）、将改写为「原名（已退役 时间）」的历史记录条数、未过期异步对象提示；
    第二步要求**输入渠道全名**解锁红色「确认退役并删除」（GitHub 式二次确认）。确认后调 retire，
    结果逐项 toast；失败保留弹窗展示原因。
  - 用量列在「已用 + 剩余」都为 0 时收敛为单个静默 `—`（tooltip 说明上游未回报余额），
    不再并排渲染两个 `$0`；任一侧非零时保留双值。
- **渠道状态**（"Channel status"，路径 `/connections/health`）：
  - 顶部汇总渠道数、可用目标、窗口请求与加权成功率（扁平指标条，不占首屏）；
  - 渠道表按「不可用 → 降级 → 服务中 → 已暂停 → 未接入路由」排序，
    列含状态、可用目标/成员、请求、成功率、p50/p95、成本；
  - 展开渠道行复用「模型状态」表，定位具体上游模型；
  - 实时路由已独立为 `/live-routing`；本页只保留汇总与渠道明细，移动端渠道表切卡片，不横向滚动；24h/7d 切换；**自动刷新 30s（可开关，页面隐藏时暂停）**。
  - 导航文案不再使用模糊的 "Health"，避免用户找不到渠道状态。
- **模型目录**（"Model catalog"，路径 `/connections/catalog`）：全局模型元数据、匹配规则、声明渠道；不承担“是否可调用”。
  - 增加只读「价格」「健康」列：价格取声明该模型的渠道 `pbr_prices`（存在多条时给区间，
    如 `¥0.8–1.2 / ¥2.4–3.6`，无价格显示 `—`）；健康取 `/api/model-status` 经渠道
    `model_mapping` 映射后的上游模型汇总（请求数 + 成功率环），无样本显示 `—`。
  - 两列只读，不改变模型编辑契约；价格的唯一写入口仍是渠道 Sheet「上游单价」页签。
  - 模型目录编辑 Sheet 新增「上下文窗口」（tokens；空/0 = 未知，负数拦截）；列表只读显示该值
    （未知显示 `—`）。它只服务用量页的窗口填充率，**不参与选路、限流或拒绝**，也不改变价格契约。
- 三页各自有左侧菜单项，按 `admin.channel` / `admin.models` 独立显隐；页面内无工作区页签。

### 日志

- **请求日志**：请求表 + attempts 时间线；筛选栏一行（时间、路由、状态），高级筛选按需展开。
  - 新增「客户端」「会话」「脱敏」三列：客户端展示后端给的 `client_name`，库/脚本显示为「脚本」
    （`client_group=script`）；会话显示 `session_id` 的短形式，点击进入会话详情；脱敏列显示
    `—` / `N 处` / `已拦截`（`masked_count`/`mask_blocked`）。高级筛选新增
    客户端下拉（按 `client_group` / `client`）、会话搜索（`client` / `session`）与脱敏开关
    （`masked`）。
  - 详情弹窗新增「上下文」卡片：窗口填充率（`context_tokens / context_window`；`window=0`
    时只显示 token）、7 个分区的 token 条与物品列表、`counted`（已按上游计数校准）/
    `estimated` 徽标；`context_status != ok` 时显示原因，**不得渲染 0% 或伪造窗口**。
  - **窗口 KPI 条**：筛选栏底部固定四格「成本 / 请求数 / RPM / TPM」，数据源为当前时间区间的
    `GET /api/stats?group_by=lane` 汇总（RPM/TPM 按窗口分钟数摊平）；**不按车道/渠道/密钥等
    明细筛选收窄**，标签必须写明是窗口总量，避免被误读为当前过滤结果。
  - **视图密度**：桌面提供「表格 / 卡片」切换并记忆到 localStorage；卡片模式每行展示
    `路由 → 渠道 / 模型`、状态、时间、首字/总耗时、输入/输出与费用，点击展开详情；
    移动端固定卡片，不显示该切换。
  - **导出**：页头提供 CSV / NDJSON 导出，直接把当前过滤条件带给 `GET /api/logs/export`；导出中禁用按钮并显示进度；超过 31 天或 10 万行由后端拒绝，toast 提示收窄条件。
  - **实时 tail**：自动刷新档位 Off / 2s / 5s / 10s（默认 Off）；页面隐藏时暂停、可见时恢复；切换筛选或翻页时保持档位并立即重取一次；新行不打断当前展开行。
  - 空态给「清除筛选」；请求失败给 `ErrorState` + 重试，**不得**把失败渲染成「没有日志」。
  - **选路前失败的日志**（缺少 `X-PBR-Lane`、未知车道等，没有渠道）：渠道列显示 `—`，
    tooltip 给出 `error_summary`；**不得**把占位 `0` 渲染成「#{0}」（会被误读为渠道故障）。
- **会话**（`/logs/sessions`）：网关视角的会话聚合，**不是**本机 agent 会话文件浏览。
  - 顶部窗口 KPI：会话数 / 请求数 / Token / 成本（当前时间区间总量，不按筛选收窄；标签写明窗口总量）。
  - 列表列：会话（短 id + 最近客户端）/ 最近活动 / 请求数 / Token（输入、输出、缓存）/ 成本 /
    模型 / 上下文峰值（有窗口时显示百分比条，否则 token）/ 错误数。桌面表格、移动卡片；
    分页每页 50、上限 100。
  - 筛选：时间区间、客户端、模型、车道、会话搜索；排序按最近活动 / 请求数 / Token / 成本。
  - 详情：会话摘要 + 上下文卡片 + 上下文填充曲线（`context_series`）+ 请求时间线
    （每项可打开请求详情）；「查看该会话全部请求」跳到 `/logs/requests?session=<key>`。
  - 会话不存在给 404 可读错误；空态/错误态/加载态与请求日志同一套，不把失败渲染成空态。
- **上下文**（`/logs/context`）：最近请求的 prompt 组成与窗口占用。
  - 列表列：时间 / 请求模型 / 会话 / 上下文 token / 窗口占用百分比 / 状态；点击详情打开完整
    7 分区上下文卡片（`GET /logs/{id}`）。
  - 数据源 `GET /api/logs?context=true`，只列带 `context_status` 或 `context_tokens>0` 的请求；
    时间区间默认当天，可改。`window=0` 只显示 token，不显示百分比；`status != ok` 显示原因。
  - 空态说明“新流量到达后出现”；错误态用 `ErrorState`，不得伪装成空态。
- **脱敏**（`/logs/masking`）：配置与观测同页，**不把原值或正文渲染到页面**。
  - **顶部状态条（强制）**：先回答「现在到底有没有在脱敏」。`active=true` 显示绿色
    「脱敏已启用 — 密钥 · 个人数据 · 本地模型 · 新请求在离开网关前会被脱敏。」，
    `active=false` 显示琥珀色「脱敏未启用 — 当前不会脱敏任何内容…」。
    状态只取自**已保存**的设置（草稿未保存不算生效），并逐项列出当前生效的检测路径，
    不让操作员对着三个复选框自行推断。`data-privacy-status=active|inactive` 供 L3 断言。
  - 顶部 KPI：窗口内命中处数 / 受影响请求 / 被拦截请求 / 模型状态（已启用、已下载、加载中、失败原因）。
  - 设置卡：密钥、个人数据、本地模型三个开关；模型 `required`、`min_score`；个人数据 kinds 复选
    （默认按 privacy-spec §4）；自定义词（换行分隔，any-case / whole 两个复选）；自定义规则
    （kind + prefix 或 regex，最多 32 条）；actions（按 kind 选 mask/warn/block）；allow 列表；
    shape 开关。保存走 `PUT /api/privacy/settings`，写后回读；422 显示字段级错误。
  - 预览：文本框 +「预览」，调用 `POST /api/privacy/preview`，左右显示输入/输出与命中列表
    （kind/by/placeholder/head+len）；预览不落库、不登记仓库。
  - 记录表：时间 / 客户端 / 模型 / 命中处数 / 状态 / 是否拦截；筛选时间、kind、by、action、
    blocked、client、model；详情 Sheet 展示 `mask_hits` 全量（**不含原值**），并提供跳到
    `/logs/requests?session=...` 的入口。
  - 模型未下载时显示大小与「下载」按钮；下载中轮询 `GET /api/privacy/model`，失败显示原因与重试。
  - 空态：未开启脱敏时给「去开启」；无命中给「当前窗口没有脱敏记录」；错误态用 `ErrorState`，
    不得伪装成空态。
- **配置审计**：事件流；固定列宽，不换行，用户名/方法/HTTP 状态保持单行；支持按当前过滤条件导出 CSV。
- **后台任务**：活跃/历史任务；移动端卡片，桌面表格；列表分页（每页 20），活跃任务 8s 轮询。
- 请求 / 会话 / 上下文 / 脱敏 / 审计 / 任务均从侧边栏进入；页面内不再有 `LogsTabs`。

## 7. 状态词汇

| 状态 | 含义 | 色调 |
|---|---|---|
| 可调用 / Serving | 至少一个成员可选 | success |
| 降级 / Degraded | 部分成员不可用 | warning |
| 全部不可用 / Down | 无成员可选，请求 503 | danger |
| 已暂停 / Paused | 人工停用，保留成员链 | neutral |
| 自动暂停 / Auto-paused | 系统因连续失败停用 | warning |
| 冷却中 / Cooling down | 软故障冷却 | warning |
| 限流中 / Rate limited | 上游 429 减速中（`paced_until`），成员**仍可用** | info（不是 warning） |
| 上游拒绝 / Upstream rejected | 连续**配置可疑**拒绝 N 次；成员仍可选，不代表成员故障；请求级 400 不计入 | warning |
| 熔断中 / Circuit open | 熔断退避 | warning |

- 状态 = 图标 + 文案，颜色只做强化；不得只靠颜色。
- **「限流中」与「冷却中」必须是两个独立状态**（routing-spec §4.1.1）：前者是上游要求放慢
  （`paced_until`，`available=true`），后者是成员故障（`cooldown_until`，`available=false`）。
  不得把两者合并成同一个告警色/同一句文案——合并会让运维把"正常限流"误读成"渠道坏了"。
- 手工停用是 **Paused**，不是 Disabled；`Delete`/`Disable` 不作为常驻红色文字动作。
- **「上游拒绝」只陈述事实，不替运维下结论**：`upstream_reject` 可能是内容审查/参数不支持
  （只针对这一份请求），也可能是网关没转发上游必需的头（配置问题）。**请求级 400 不累计
  `reject_streak`**；只有后端判定为配置可疑的连续拒绝才显示「上游连续拒绝 N 次」，
  且**不得**写成「需修复配置」；是否改配置由运维结合上游报文判断。达到后端阈值后成员
  进入短期冷却，控制台按「冷却中」展示。

## 8. 编辑面

- 渠道、API 密钥、路由编排器、共享链编辑器使用**右侧 Sheet**（`DialogContent variant='sheet'`）：
  - 固定宽度档（640 / 1040），header/footer 钉住，正文单层滚动；
  - Escape/遮罩关闭，未保存草稿仍走原有确认；
  - 确认框、只读详情、模型探测/参数覆盖等选择器继续用居中 Dialog。

## 9. 上游价格（峰谷）

- 价格键仍为**渠道 × 模型**；单价支持按时段：
  - `timezone`（默认 `Asia/Shanghai`）；
  - 有序 `bands`：`days`、`start`、`end`、`input`、`output`、`cache_read`、`cache_write`（`days` 指时段**起始日**，跨午夜时段归起始日）；
  - 行级 `input`/`output`/`cache_read`/`cache_write` 即兜底价（不另设 `fallback` 对象）；按请求**开始时间**匹配第一条命中。
- 旧 `pbr_prices` 单行价视为全天一个 band，无需迁移。
- 日志记录 `price_band`（命中下标，-1=兜底）；`POST /api/stats/rebuild` 可按 `ts` + 当前价格表重算。
- UI 在渠道 Sheet「价格」页签提供：
  - 周视图网格（7 天 × 时段）+ 行内时段编辑；**当前生效价**预览；
  - 校验错误就地提示（非法 HH:MM、空 `days`、超过 64 条）；
  - **DeepSeek 官方峰谷预设**按钮：只填结构，数值由运维按采购价修改，不写死部署数据；
  - **批量粘贴导入**：JSON 数组或 CSV（`model,input,output,cache_read,cache_write,timezone,days,start,end`），解析后先表格预览，确认后随渠道 `PUT` 提交；预览复用 `?dry_run=true`。

## 9.1 出站准入（渠道 Sheet「并发」页签）

- 渠道 Sheet 新增「并发」页签，按渠道声明的模型编辑 `rate_limits`（routing-spec §3.2、
  [ADR 0012](adr/0012-outbound-admission-control.md)）：`model`（从渠道模型清单选择）、
  `max_concurrency`、`max_rpm`、`queue_limit`、`queue_wait_seconds`。
- **默认全部留空 = 不限制**；`max_concurrency` 提供「自动」选项（存 `-1`，AIMD 自适应），
  选中后不显示数字输入，改为展示运行态学到的当前上限。
- `queue_limit = 0` 用默认 32；`queue_wait_seconds = 0` 表示不排队。
  行内校验整数范围（`max_concurrency >= -1`，其余 `>= 0`）与 model 不重复；
  保存随渠道 `PUT` 提交，`?dry_run=true` 预览。
- 渠道列表/模型目录只读展示当前生效的并发与 RPM 上限（无配置显示 `—`，自适应显示「自动 (当前 N)」）；
  该页签**不参与**车道编排，也不得变成新的路由开关。
- 实时路由/健康视图展示成员的 `inflight` / `rpm_used` / `queued` / `adaptive_limit`
  （运行态，重启清零）；请求日志的 `throttled` 与 `wait_ms` 可检索。

## 10. 验收

- 侧边栏是分组导航：控制中心 = 实时路由、数据概览、路由、渠道与模型（渠道/渠道状态/模型目录）、API 密钥、用量（请求/会话/上下文）；系统 = 脱敏、审计日志、系统任务、设置（站点与品牌/模型与路由/控制台内容/运维）。设置分组在侧边栏内展开，进入设置页后主侧边栏保持常驻；旧路径 302 后落在新页。
- 实时路由从概览移出后，概览不再渲染该卡；`/live-routing` 单页**不含时间区间与问题筛选**，保留 `lane` 深链、SSE 与最近请求，并在同页下方按固定 30s 窗口展示各渠道输出速度（每 5s 刷新）；不得再出现独立「实时仪表盘」入口。
- 侧边栏「用量」可展开 请求/会话/上下文，`日志` 可展开 审计/任务，`脱敏` 是系统区的独立入口；
  所有子项都是真实路由，刷新/后退/深链不丢；页面内没有重复页签。
- 脱敏页：**默认关闭**（三个总开关为 false，页面显示「脱敏未启用」状态条）；
  「应用推荐配置」只重置检测口径、不打开总开关；设置保存后回读一致；预览只显示占位符与命中元数据；
  记录表可筛选、可打开详情；页面任何位置都不出现原值或请求正文；模型未就绪时显示状态与下载入口。
- 上下文页：列表显示 token/窗口占用/状态；详情卡片显示 7 分区；无窗口不伪造百分比。
- 会话页：列表/筛选/排序/分页可用；详情含摘要、上下文卡片、填充曲线与请求时间线；`/logs/requests?session=<key>` 能回到该会话的请求列表；`session_not_found` 显示可读错误。
- 请求详情「上下文」卡片：有窗口时显示填充率，无窗口时只显示 token；`context_status != ok` 显示原因，任何情况下不得把缺失上下文渲染成 0%。
- 概览：缓存命中率在 `input_tokens=0` 时显示 `—`；客户端分布与 53 周日历有数据/空态/加载态；日历无数据日期为空白格。
- 模型目录：「上下文窗口」写入/回读一致，0 显示 `—`，负数被拦截；不改变选路结果。
- 渠道/密钥/路由/共享链编辑器为右侧 Sheet；footer 始终可见。
- Keys/Audit 表格在 1440px 下不出现逐字换行；窄屏可横向滚动或切卡片。
- 移动端页头不截断标题；概览 KPI 2 列；任务页不出现 900px 横向表格。
- 状态词汇统一为 Serving/Degraded/Paused/Auto-paused；手工停用不显示为故障红。
- 日志导出 CSV/NDJSON 可下载，列与限制符合 api-spec §5.5.1；超限错误可读。
- 审计 / 渠道 / 密钥导出 CSV 可用，且不包含任何明文密钥（api-spec §5.5.2）。
- 日志实时 tail 档位生效，页面隐藏时暂停；渠道状态自动刷新可开关。
- 空态 CTA 覆盖渠道 / API 密钥 / 路由 / 模型目录；错误态不得伪装成空态（Keys / About / Legal / Settings）。
- 命令面板可搜渠道、API 密钥、模型、路由与 Request ID，键盘可达。
- 价格峰谷：周视图、当前生效价、DeepSeek 预设、批量粘贴导入均可用；非法时段被拦截。
- 视觉基线：分组导航页面在 1440 / 390 两档无横向溢出、无逐字换行；深色/浅色一致（§11）。
- E2E：Playwright 冒烟覆盖分组导航的全部真实路由（§12 与 test-spec §8）。

## 11. 视觉基线（统一，不换皮）

- 目标：统一设计语言与密度，不重做信息架构、不替换组件库。
- **Token 单一来源**：间距（4/8/12/16/24/32/48）、圆角（6/10/14）、字号（12/13/14/16/18/24）、三级阴影全部走 CSS variables + Tailwind theme；禁止新增散落的 arbitrary value。
- **页面壳唯一**：`ConsolePage` 为唯一实现；删除 `SectionPageLayout` 及重复的标题/操作/footer portal 逻辑。
- **表格密度**：桌面行高 44px、紧凑 40px；移动端卡片；不出现 900px 横向滚动。
- **图表统一**：一套调色板（success / warning / danger / neutral + 两个主色）、统一轴/网格/tooltip；禁止手写 div 柱状图与散落 SVG（现有手写图逐步替换为统一图表组件）。
- **三种状态组件**：`EmptyState` / `ErrorState` / `Skeleton` 统一实现；错误必须可重试，空态在有创建动作的页面必须给 CTA。
- **动效**：尊重 `prefers-reduced-motion`；只做状态过渡，不做装饰动画。
- **深色/浅色**：同一 token 映射，两套主题截图对照验收。

## 12. 交互完整性

- **命令面板**：导航 + 实体搜索（渠道 / API 密钥 / 模型 / 路由 / Request ID）；250ms 防抖、分组各 ≤5 条、键盘可达、无匹配给明确空态；只读现有端点，不新增后端搜索面。
- **自动刷新**：日志 / 渠道状态 / 后台任务提供档位或开关；页面隐藏时暂停。
- **列表视图记忆**：日志「表格 / 卡片」选择写入 `localStorage`，刷新与深链后保持；
  切换视图不重置筛选、页码或实时 tail 档位。
- **错误处理**：查询失败 = `ErrorState` + 重试；mutation 失败 = toast + 表单内联错误；不得把失败渲染为空态或默认值。
- **空态**：`DataTablePage.emptyAction` 必须使用（有创建动作的页面）；无创建动作给「清除筛选」。
- **危险操作**：统一 `ConfirmDialog`；批量删除显示数量与不可撤销提示。
- **无障碍**：可排序表头带 `aria-sort`；图标按钮 `aria-label` 走 i18n；焦点可见；保留 Skip link。
- **i18n**：新增文案 7 个 locale 同步；`aria-label` / `sr-only` 不得硬编码英文。

## 13. 视觉系统：Paper Ledger（2026-11-15 用户选定）

> 参考：Langfuse 的编辑气质、OpenStatus 的数据表、Twenty 的克制工作台。只借鉴版式与交互，
> 不复制代码或资产。目标是让 PBR 从「通用 admin 模板」变成有工程气质的单用户运维台账。

### 13.1 设计原则

1. **纸面而不是玻璃**：暖纸底、墨黑文字、1px 细线；靠层级、对齐、留白产生设计感，不靠大面积渐变和阴影。
2. **一个信号色**：酸性黄绿只用于当前导航/选中/高亮，不用于状态；状态只用绿/琥珀/红圆点 + 文字。
3. **数据先于装饰**：数字统一 tabular；页面上半部回答「现在怎么样」，下半部才是明细。
4. **一屏一个主动作**：页面头部最多一个 ink primary；其余动作收进工具条或行菜单。
5. **表格是台账，不是 Excel**：分组、粘性表头、行选中、右侧检查器；空值统一 `—`，不保留无意义列宽。
6. **全站同一套壳**：页面标题、工具条、数据面、检查器、空/错/载入态使用同一批共享组件。

### 13.2 Token（`web/src/styles/paper-ledger.css`）

| 类别 | 值 |
|---|---|
| 画布 / 纸面 | `#F3F0E8` / `#FBF9F2` |
| 墨色 / 次级文字 | `#1B1A17` / `#6B6458` |
| 细线 / 输入线 | `#D8D0BF` / `#CFC6B3` |
| 高亮 | `#E4F36A`（acid，只做选中/active） |
| 状态 | success `#2F7D57` · warning `#B45309` · danger `#B42318` · info `#0E7490` |
| 标题 | Lora（`font-serif`），26–30px，`-0.02em` |
| 正文 / 数据 | Public Sans 13–14px；数据 `tabular-nums` |
| 微标签 | 等宽 10px，大写，`0.12em` 字距 |
| 圆角 | 控件 6px、面板 10px；不再使用大圆角胶囊作为默认容器 |
| 行高 | 桌面表格 44px、紧凑 40px、表头 32px；页头 56px |
| 阴影 | 纸面只保留 0–2px 的接触阴影；浮层允许单层柔和大阴影 |

深色主题同 token 映射：`#171613` 画布、`#1F1D19` 纸面、`#ECE6DA` 墨色、同一 acid 高亮。
命名 theme preset 仍可覆盖颜色；不选择 preset 时使用 Paper Ledger。

### 13.3 共享组件

- **PageHeader**：微标签（模块名）+ 衬线标题 + 一行说明 + 右侧动作；下方 1px 细线。
- **SummaryStrip**：一条横向「台账摘要」，用竖线分隔，不做四张彩色 KPI 卡。
- **LedgerToolbar**：搜索、筛选项、视图切换、密度切换在同一行；移动端收进 Sheet。
- **FilterRail**：桌面 200px 左轨（渠道/日志），移动端 Sheet；选项带计数，状态用圆点。
- **DataSheet**：细线边框、粘性表头、行 hover 酸性浅洗、选中行左侧 2px 墨线；不再使用悬浮卡片包表格。
- **StatusDot**：`● 文字`，颜色只在圆点；状态药丸只用于标签，不用于健康结论。
- **Metric**：数值 + 单位 + 说明三层；数值 tabular，说明 11px muted。
- **Inspector**：右侧 380px 抽屉，不遮挡主表；tab 为 概览 / 配置 / 最近请求。
- **LedgerChart**：墨线 + 酸性面积，细网格，等宽轴标签；禁止彩色渐变面积图。

### 13.4 页面蓝图

- **渠道**：摘要（总数 / 可用 / 需关注 / 暂停）→ 工具条 → 左侧筛选轨 + 分组台账
  （Healthy / Attention / Paused）→ 行点击打开右侧检查器。列合并为
  Channel（名称 + 协议 + 标签）、Health（状态点 + 延迟/最近探活）、Usage、Created、Actions；
  Actions 只保留「编辑」与 `⋯`，测试/复制/删除收进菜单。空 `Usage` 不占独立列宽。
- **实时路由**：整宽拓扑台账（车道 → 网关 → 成员）→ 渠道速度台账
  （Channel / Output speed / Live traffic / Req-rate / p50 / Success / Status），
  有流量的行带速度条，空闲渠道收进折叠脚注；不使用大卡网格。
- **概览**：顶部台账摘要（成本/Token/请求/成功率）→ 模型健康台账（两列布局）
  → 趋势图（墨线 + acid 面积）→ 用量日历。去掉重复的大卡片和装饰性渐变。
- **日志**：筛选轨 + 粘性工具条 + 高密度日志台账；时间条/延迟条用统一图形；
  行点击打开 inspector；表格/卡片切换与密度记忆保留。
- **API 密钥 / 模型目录 / 脱敏 / 审计 / 任务**：复用同一 DataSheet + 工具条 + inspector；
  页面只保留本领域特有列和摘要，不另造壳。
- **设置**：左侧设置域 + 页面内分节；表单改为「字段行 + 说明 + 操作」的纸面表单，
  不再每个区块套一张浮卡。
- **移动端**：筛选轨变 Sheet；台账行变三段式行卡；inspector 全屏；不横向滚动。

### 13.5 落地顺序与验收

1. **Foundation**：token、字体、页面壳、表格/状态/工具条/摘要/检查器共享组件；先让全站换气质。
2. **高频页**：渠道 → 实时路由 → 日志。
3. **分析/配置页**：概览 → API 密钥 → 模型目录 → 脱敏 → 设置 → 审计/任务。
4. **验收**：L0/L1 全绿；L3 真实浏览器在 1440 / 1024 / 390 三档截图；
   亮/暗主题各一遍；文本对比度 ≥ WCAG AA；不出现横向滚动；
   所有空态/错误态/加载态有对应视觉；不保留旧模板的彩色 KPI 卡与浮夸阴影。
